Limits

Section titled “Limits”
  • No independent reference, so this shows consistency between the two solves, not accuracy.
  • The recording is H.264 and the USB-3372 sheet lists MJPG and YUY2, so the exact model stays open.
  • Frame stamps fall about 5.2 ms after mid-exposure, so td here isn't a physical delay.

How it was run

Section titled “How it was run”
  • cam0 at 30 Hz, cam1 at 10 Hz, default IMU noise, t_ga on, camera intrinsics free. Batch of 2026-11-03.
