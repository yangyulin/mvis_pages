Limits

Section titled “Limits”
  • No independent reference. These values show what MVIS solved, not how close they are to the truth.
  • Unit A lever z sits about 25 mm above unit B, beyond the roughly 10 mm uncertainty for this motion. This is still open.
  • Accel z scale stays near 0.93 to 0.94 because z barely sees gravity in this motion, so it isn't a sensor property.

How it was run

Section titled “How it was run”
