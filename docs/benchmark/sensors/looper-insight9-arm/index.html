Limits

Section titled “Limits”
  • No reference exists for these recordings, so the table shows repeatability, not accuracy.
  • The arm program rotates mostly about one axis, so lever arms and the outer lens fit are less well determined than on the hand-held page.
  • Repeatability here rests on 2 recordings.
