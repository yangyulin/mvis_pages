How it was run

Section titled “How it was run”
  • EUCM camera model, Kalibr IMU model, t_ga on, camera intrinsics free, seeded from the camera-only fit. Batch of 2026-11-03. This solve uses physical camera 1 as its base, so cam0 and cam1 on this page are physical cam1 and cam0.
