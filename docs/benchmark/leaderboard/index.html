Leaderboard

The calibration results of MVIS, Kalibr and Basalt on the same datasets: every parameter as median ± sd (n) across recordings, with the differences between tools. This is batch 2026-11-02b. The records live in calibench-vi/results, and the Space shows the same tables.

There is no ground truth. Differences show where tools disagree, not who is right. Spread shows repeatability across recordings, not accuracy. The MVIS authors run this board and made every run, including Kalibr and Basalt.

Kalibr on T7 was re-run on 2026-11-02 on the corrected bags; the other Kalibr and Basalt runs are from 2026-10-22 or earlier. Data settings still differ from MVIS on T6, T7 and T8, so read those three with care. More in Methodology.

How to read this
  • Spread shows repeatability across recordings, not accuracy. A tool can repeat well and still be biased.
  • 448.50 ± 0.48 (10): median ± sd across the 10 recordings that tool solved. With 3 or 4 recordings the sd itself is rough.
  • (3/15): this tool has 3 of the family's 15 recordings.
  • fixed: Kalibr doesn't estimate this value. Its camera + IMU runs take intrinsics and baselines as input from an MVIS export, and T7 ELP-L readout is held at 0. The spread here isn't repeatability.
  • shown: the tool uses a different model here, so the value has no difference next to it.
  • other model: Kalibr's coefficients here belong to a different lens model.
  • not in model, not reported, no run, no data, no RS model, not in one run: the tool has no value for this row, and the words say why. no run means the tool never ran with this sensor; not in one run means it ran with each sensor, but no single run holds both ends of the baseline. not run, in the recordings line: the tool has no run for the family.
  • Differences: the column header gives the subtraction, using stored medians. No tool is the reference.
  • ◆: the difference is larger than the larger of the two sds. It marks disagreement, not an error in either tool.
  • ≠n: the two medians come from different numbers of recordings.
  • ≠ model: the tools' models differ, so no difference is shown. fit: reprojection error measures fit and isn't comparable across models.
  • ‡ td: MVIS splits the IMU into gyro (td) and accel (td + t_ga); Kalibr and Basalt have one timeline. Basalt − Kalibr is the like-for-like check.
  • Each family folds; the first is open. Click a family's title to open or close it.

Notes

Like for like: MVIS values are the camera rows of the T6 camera + IMU solve with the default IMU model. MVIS uses two corners per tag, non-base cameras at 4 Hz or lower and an estimated board shape; Kalibr has none of these.

Note: MVIS has no separate T6 camera-only regression row: the MVIS column is the camera calibration of the T6 camera + IMU rows (calyx model, intrinsics refined in cam-IMU), against Kalibr's 10 camera-only runs.

Basalt: t265 pair (kb4, fisheye 2 snapped onto fisheye 1) and Blackfly alone (pinhole-radtan8, a different model from radtan: its intrinsics are shown only); no camera-only Basalt run holds both devices, so no baselines to the Blackfly.
