Leaderboard

MVIS, Kalibr and Basalt calibrated on the same recordings, with one leaderboard per dataset. This is batch 2026-11-02b. The records live in calibench-vi/results, and there is an interactive version with every parameter.

How to read a score

Section titled “How to read a score”
  • The score measures repeatability, not accuracy. It compares how much each parameter varies across recordings of the same rig. These datasets have no ground truth, so a method can repeat well and still be biased.
  • Lower is better, and 1.00 is the best. A score of 2 means twice the spread of the best method on that parameter, averaged over the parameters. Scores are capped at 10.
  • 10 (not run) means the tool cannot run that family, and the dataset score counts it. n/a means it ran but nothing it estimates could be scored there, so that family is left out.
  • Compare within a dataset, not across datasets.

Kalibr on T7 was re-run on 2026-11-02 on the corrected bags; the other Kalibr and Basalt runs are from 2026-10-22, on data that correction does not touch. Data settings still differ from MVIS on T6, T7 and T8, so read those three with care. Full rules: Methodology.

Family numbers

Section titled “Family numbers”

Each family is one test in the MVIS regression suite. The numbers changed on 2026-11-02 so the VI-Rig datasets come first, and older material uses the old ones. New (old): T1 (T3), T2 (T4), T3 (T1), T4 (T2), T5 (T5), T6 (T11), T7 (T8), T8 (T12), T9 (T6), T10 (T7), T11 (T10), T12 (T9).
