VI-Rig: 5 IMUs + 4 cameras

Our rig with two RealSense T265 units (two global-shutter fisheye pairs) and five IMUs: an Xsens MTi as base, a GX3-25, a GX3-35 and the two T265 IMUs. A one-off MVIS study of 7 recordings, not part of the leaderboard batch or the regression suite. Kalibr and Basalt were not run on it.

our data 4 global-shutter fisheye cameras5 IMUs, 100–500 Hz7 recordingsMVIS only CC BY-NC 4.0 (gated)

Separate study · batch 2026-11-02 · not part of the leaderboard batch

How MVIS calibrates it → ExampleDownloads → Dataset pageThe device → Device wikiThe data → Hugging Face

Repeatability, not accuracy. There is no ground truth: a small spread shows that a tool repeats, not that it is right, and a difference shows that two tools disagree, not which one is wrong. The MVIS authors made every run; only MVIS was run on this set.
