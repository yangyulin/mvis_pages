Datasets

This page lists every dataset we use to test and benchmark MVIS, where to get it, and its licence.

  • Where the data lives: the calibench-vi/datasets repository on Hugging Face. Calibench is the name of our calibration benchmark.
  • What it hosts: our own VI-Rig recordings, two partner recordings, third-party sets whose licence allows us to share them again (CC BY 4.0), and result files for some sets (tum-fisheye/results/, uzh-fpv/results/, virig-5imus-4cams/results/).
  • What it does not host: all other third-party sets. For those, a download recipe fetches the files from the original site.
  • Results: the reference results for each set are on the leaderboard and in calibench-vi/results.

VI-Rig: our own recordings

Section titled “VI-Rig: our own recordings”

We built the VI-Rig to research calibration of rigs with several cameras and several IMUs. An IMU (inertial measurement unit) is a gyroscope plus an accelerometer. Each dataset below is one sensor setup on the same frame, recorded as ROS1 bags (one bag per recording) while we move the rig in front of a calibration board.

4 IMUs + 3 cameras, ArUcosame 3 cameras4 IMUs (3 in recordings 11–17)ArUco tags17, 102–139 s117 GBnot benchmarked

5 IMUs + 4 camerastwo T265 pairs, all global shutter5, 100–500 HzAprilGrid7, 41–64 s28 GBresults · example

Terms used in the table:

  • Global shutter: the camera exposes every row of the image at the same time.
  • Rolling shutter: the camera reads the image out row by row, so each row has its own capture time.
  • AprilGrid: a printed grid of AprilTags, square codes that the software finds and identifies in each image.
  • ArUco: another family of square marker tags.

Licence and access

Section titled “Licence and access”
  • Licence: CC BY-NC 4.0. Free for research, teaching and other non-commercial use, with attribution.
  • Gated: log in to Hugging Face and accept the terms on the dataset page. Access is granted at once.
  • Benchmark exception: anyone, a company included, may run a calibration tool on these recordings to produce Calibench results and publish them with attribution.
  • Other commercial use: needs a separate licence. Ask in the Community tab of the Hub repository or at licensing@openmvis.com.

Download

Section titled “Download”

Accept the terms on the Hub first, then set HF_TOKEN to a read token from your Hugging Face settings (or log in once with hf auth login, after pip install huggingface_hub).

  • Where files land: in $MVIS_DATASETS (default ~/Datasets). The example configs refer to the data as ${MVIS_DATASETS}/....
  • Checks: mvis datasets checks each file’s size and SHA-256 checksum.
  • Without MVIS: use the Hugging Face CLI; each dataset page gives the exact command.

Third-party datasets

Section titled “Third-party datasets”

These sets come from other groups. Each keeps its own licence and citation; please cite the original authors.

  • Hosted: the calibration recordings of sets under CC BY 4.0, converted to ROS1 bags. A .provenance.json beside each bag records the source address, the source checksum and the conversion steps.
  • Recipe: we never copy these files. The Hub’s recipes/download.py fetches them from the original site and checks them.
  • Key: mvis datasets download --dataset <key> also fetches from the original site and checks each file. For the hosted sets it gets the original archives; mvis datasets convert then turns them into ROS1 bags. Urban fisheye and part of PennCOSYVIO have no checksum in the catalog; add --allow-unverified to fetch them unchecked.

Citation

Section titled “Citation”

If you use the Calibench data, please cite:

  • Calibench, for any of the data.
  • The MVIS paper, for the VI-Rig sets with 4 IMUs (3 cameras, 3 cameras ArUco, 4 cameras). The 5-IMU set has no paper yet; cite Calibench for it.
  • The original paper of every third-party set you use. The dataset card lists them.
