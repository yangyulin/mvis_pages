Reference results

Section titled “Reference results”

Per-config Kalibr and MVIS reference results (dated snapshots, JSON against the benchmark schema) are published in calibench-vi/results — see the Kalibr/ and MVIS/ trees (virig_* and mvis_* configs) — and are shown on the leaderboard.
