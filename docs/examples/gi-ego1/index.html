GI Ego1

Head-worn fisheye stereo from GiLabs with a rolling shutter and a 200 Hz IMU. MVIS estimates the readout along with the rest of the rig.

Rolling shutterStereo200 Hz IMUCC BY-NC 4.0

Limits

Section titled “Limits”
  • One recording, with no independent reference. These values show what MVIS solved, not how close they are to the truth.
  • Gyro scale solves 3 to 4 % below 1 on all axes. We have not confirmed the cause.

How it was run

Section titled “How it was run”
  • Recording converted to EuRoC layout, camera-only solve per camera, then camera + IMU with camera intrinsics free, t_ga on and the rolling-shutter readout estimated. Batch of 2026-11-03.
  • sha256 of the recording: ca4b6bf961f687762de94f941891e3b32eb5edf174f5529f5470eaecdb3a883b
