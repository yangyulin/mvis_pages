Notation & glossary

Use this page to look up a symbol, a frame or a sign convention. Every equation on this site uses the symbols below.

The frame and transform conventions follow OpenVINS. Result files use their own XtoY names (below).

Transforms

Section titled “Transforms”

A rotation is written BAR{}^{A}_{B}\mathbf{R}BA​R. It takes a vector expressed in {B}\{B\}{B} into {A}\{A\}{A}. A translation ApB{}^{A}\mathbf{p}_{B}ApB​ is the origin of {B}\{B\}{B} expressed in {A}\{A\}{A}. Together they form the transform BAT{}^{A}_{B}\mathbf{T}BA​T:

Ap=BAR Bp+ApB{}^{A}\mathbf{p} = {}^{A}_{B}\mathbf{R}\, {}^{B}\mathbf{p} + {}^{A}\mathbf{p}_{B}Ap=BA​RBp+ApB​

Result files and code use a different spelling

Result files write T_C0toI for the transform taking points from {C0}\{C_0\}{C0​} into {I}\{I\}{I}. It is the same object as C0IT{}^{I}_{C_0}\mathbf{T}C0​I​T. The XtoY names read left to right, in the direction of the mapping: R_wtoI is wIR{}^{I}_{w}\mathbf{R}wI​R, R_atoI is aIR{}^{I}_{a}\mathbf{R}aI​R, T_IstoI is IsIT{}^{I}_{I_{s}}\mathbf{T}Is​I​T. See Result formats.

Every stamp is mapped onto one reference clock, the base-IMU clock.

A board corner seen in row vvv of camera iii was captured at

The sign convention matters. td is added to the sensor’s own stamp to reach base-IMU time. A positive td means the camera stamps run early: the image was captured later than its stamp says. mvis apply-calib re-stamps each message as stamp + td.

Conventions worth stating once

Section titled “Conventions worth stating once”
  • Quaternions: result files store rotations as matrices and log(R) rotation vectors, not quaternions. Simulator trajectory files (mvis.simulation) use JPL quaternions qGtoIq_{GtoI}qGtoI​, as in OpenVINS. The Basalt export uses Hamilton quaternions, as Basalt does.
  • Error states (the small corrections around the current estimate) are defined:
    • multiplicatively for rotations, R≈R^ Exp(δθ)\mathbf{R} \approx \hat{\mathbf{R}}\,\mathrm{Exp}(\delta\boldsymbol{\theta})R≈R^Exp(δθ);
    • additively for everything else.
  • Units in result files: metres, radians and seconds; summaries add _mm and _ms copies where the name says so.
  • Board points are flat and known by default (estimate.board_points: false). Board errors then go into the calibration: a wrong tag_size gives a scale bias on translations, and a bent board biases the focal length, gyro scale and lever (Why calibrate the board shape). With estimate.board_points: true, MVIS solves one height hkh_khk​ per corner.

Glossary

Section titled “Glossary”
  • Factor: one term of the cost the solver minimises.
  • Residual: the error a factor measures, predicted minus observed.
  • Jacobian: the derivative of a residual with respect to a state variable.
  • Lever arm: the translation between two sensors, e.g. IpCi{}^{I}\mathbf{p}_{C_i}IpCi​​.
  • Incidence angle: the angle of a ray off the camera’s optical axis.
  • Specific force: what an accelerometer measures, acceleration minus gravity.
  • Pre-integration: IMU readings between two states combined into one relative motion.
  • Base / auxiliary IMU: the base IMU sets the clock and the body frame; every other IMU is auxiliary.
