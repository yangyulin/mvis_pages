## 3 Major Ways of Using MVIS

The MVIS can be used in three major ways:

- **Refinement of Kalibr Results.** Use existing Kalibr output as the
  initial guess and refine intrinsics, extrinsics, and time offsets jointly
  in the MVIS factor graph.
- **Full calibration of multi-visual-inertial sensors.** Solve every
  variable from scratch — IMU intrinsics, gyroscope intrinsics, camera
  intrinsics, IMU–IMU and IMU–camera extrinsics, time offsets, and
  rolling-shutter readout time.
- **Partial calibration of multi-visual-inertial sensors.** Lock the
  parameters you trust and solve only the rest (e.g. fix camera intrinsics
  from a prior calibration and solve only the new IMU's extrinsics).

## Full Multi-Visual-Inertial Sensor Calibration

The major calibration procedures can be summarized as:

1. Create calibration target
2. Collect data with ROS
3. Set up sensor topics
4. Initialize IMU / camera intrinsics
5. Initialize spatial–temporal calibration
6. Sensor setup
7. Estimator setup
8. Calibration
9. Refinement

Each step is documented in detail in the following sections — see
**Procedures** and **Quick Start** in the sidebar.

## What gets solved

| Quantity | Symbol | Per-sensor or pairwise | Notes |
|---|---|---|---|
| Camera intrinsics | `fx, fy, cx, cy, k1..kn` | per camera | rad-tan or equidistant |
| IMU noise model | `σa, σg, ba, bg` | per IMU | Kalibr or RPNG model |
| Gyroscope intrinsics | scale + misalignment | per gyro | Kalibr or RPNG model |
| Camera–IMU extrinsics | `R_CI, t_CI` | pairwise | rotation, translation |
| IMU–IMU extrinsics | `R_IiIj, t_IiIj` | pairwise | rotation, translation |
| Time offsets | `Δt` | pairwise | sensor → reference clock |
| Rolling-shutter readout | `tr` | per RS camera | first/middle/last row |
