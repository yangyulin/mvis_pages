## How to read these pages

Every example has the same sections, so you can compare any two directly:

1. **The rig:** the sensors, their rates and what makes the dataset interesting.
2. **Getting the data:** the download, and any preparation the bag needs.
3. **Configuration:** the full launch file.
4. **Running it:** the command, and what it prints.
5. **Result:** the calibration it produced.
6. **Validation:** the same quantities from an independent source, and the
   difference. This part makes an example evidence, not just a demonstration.
7. **Reproducibility:** the code version, config and data hash you need to get
   the same numbers.

:::note[Plots are generated, not screenshotted]
The figures on these pages come from the run they document. Re-running the
reproducibility block makes them again. If a plot and the text disagree, the
plot is right.
:::
