## How to read these pages

Every example has the same seven steps, in this order:

1. **Data:** which recording and why, its board, and where to download it.
2. **Config:** the run's own config, with the lines that matter for that rig marked and explained.
3. **Run:** the one command, and roughly how long it takes.
4. **Watch MVIS calibrate:** MVIS's own player: the detected corners, then the rig's path as the solve refines it.
5. **Result:** a 3D map of the solved rig and a table of every camera and IMU: intrinsics, lever arm, rotation as log(R), time offsets.
6. **Check against a reference:** MVIS beside a published calibration and the difference, where one exists. Where none does, the page says so.
7. **Reproduce:** the MVIS version, the run date, the data and the command, to get the same numbers.

Downloads are on each dataset's own page, and comparisons across tools are on the Results pages.

:::note[Figures come from the run]
The player, the map and the tables on each page are generated from the run they document. If a figure and the text disagree, the figure is right.
:::
