## How to read these pages

Every example page is laid out like a Sensor wiki page: a header card with the photo, the key facts and links, then the same sections in this order:

- **Demo and values:** what the page shows, the scene MVIS recovered from the dataset, and the run's headline values.
- **Calibration process:** MVIS's own player: the detected corners, then the rig's path as the solve refines it.
- **Solved rig:** a 3D map of the solved rig and a table of every camera and IMU: intrinsics, lever arm, rotation as log(R), time offsets.
- **Check against a reference:** MVIS beside a published calibration and the difference, where one exists. Where none does, the page says so.
- **Config and run:** the run's own config with the lines that matter marked and explained, the command, and what you need to get the same numbers.
- **Dataset:** the recording, its board drawn to scale, and where to download it.

Downloads are on each dataset's own page, and comparisons across tools are on the Results pages.

:::note[Figures come from the run]
The player, the map and the tables on each page are generated from the run they document. If a figure and the text disagree, the figure is right.
:::
