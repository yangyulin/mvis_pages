## Config and run

```yaml title="uzh_fpv_snapdragon_outdoor_forward_cam_imu.yaml" {6-12,14,18-19}
input:
  format: ros1
  path: outdoor_forward_calib_snapdragon_imu.bag
  imu_topics:
  - /snappy_imu
board:
  board_type: apriltag
  rows: 4
  cols: 5
  tag_size: 0.075
  tag_spacing: 0.2
  tag_family: t36h11
camera_input:
  path: camera_prior_kalibr_camchain.yaml
  estimate_readout: false
solve:
  imu_intrinsics: dw_da
  estimate_t_ga: true
  sigma_g: 0.0002999232700379165
  sigma_a: 0.0025286614063113116
  sigma_bg: 2.9992327003791653e-05
  sigma_ba: 0.00025286614063113117
output:
  path: cam_imu.json
```

```bash title="shell"
mvis cam-imu -c uzh_fpv_snapdragon_outdoor_forward_cam_imu.yaml
```
