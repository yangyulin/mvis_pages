<div class="not-content rp-honest">
  <p><b>This page shows repeatability, not accuracy.</b> Repeatability is how much each tool's estimates scatter when the same rig is calibrated from different recordings. These datasets have no ground truth, so no tool is the reference, and a tool can repeat well and still be biased. Tools are compared only on recordings that every compared tool ran. Reprojection error measures how well a model fits its own data; it is not used here. The MVIS authors run this board and made every run, including the Kalibr and Basalt runs.</p>
</div>

## About these results

<details class="rp-fold">
<summary>How the verdicts are made</summary>

For each family and group of parameters we take only the recordings every compared tool ran. For each tool we measure the scatter (standard deviation) of each parameter across those recordings, and compare two tools by the median ratio of their scatters. A tool is marked more repeatable only if its scatter is at least 20 % smaller and a gap that large would rarely appear (under 5 %, Holm-adjusted within the cell) if we swapped the two tools' results recording by recording. Otherwise it is a tie: either the gap is within chance, or it is under 20 %. With fewer than 6 shared recordings no gap can pass this test (the smallest possible p is 2/2ⁿ), so those cells say "too few recordings". Values a tool received as input, and rows where the tools' models differ, are not compared. Distortion coefficients trade off against each other, so their scatter can overstate differences in the lens mapping. Each cell is a separate 5 % test; across the {tested.cells} tested cells on this page, of which {tested.naming} name a tool, one or two calls may be chance. The intervals are not adjusted for multiple tests.

</details>

<details class="rp-fold">
<summary>Agreement between tools</summary>

The parameter tables also show the differences between the tools' medians. Where two tools' medians differ by more than either tool's scatter, they disagree. ◆ marks disagreement, not an error in either tool. No tool is the reference. ‡ on a time offset: MVIS splits the gyro (td) and accel (td + t_ga) timelines, so Basalt − Kalibr is the like-for-like check there.

</details>
