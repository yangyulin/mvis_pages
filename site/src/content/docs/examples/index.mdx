## How to read these pages

Every example follows the same structure, so two of them can be compared
directly:

1. **The rig** — sensors, rates, and what makes the dataset interesting.
2. **Getting the data** — download and any preparation the bag needs.
3. **Configuration** — the launch file, in full.
4. **Running it** — the command and what it prints.
5. **Result** — the calibration produced.
6. **Validation** — the same quantities from an independent source, and the
   difference. This is the part that makes an example evidence rather than a
   demonstration.
7. **Reproducibility** — code version, config, and data hash needed to obtain
   the same numbers.

:::note[Plots are generated, not screenshotted]
Figures on these pages come out of the run they document. Re-running the
reproducibility block regenerates them — if a plot and the text disagree, the
plot is right.
:::
