Build the toolbox into a catkin workspace. Check
[Requirements](/getting-started/requirements/) first for versions; if a build
fails, [FAQ & troubleshooting](/about/faq/) collects the errors we see most.

## 1. Create the workspace

```bash
mkdir -p ./workspace/src
cd workspace/src
```

## 2. Clone OpenVINS

```bash
git clone https://github.com/rpng/open_vins/
cd open_vins/
git checkout v2.3
cd ..
```

## 3. Get OpenCV

The ROS package is enough for most users:

```bash
sudo apt install ros-melodic-cv-bridge   # Ubuntu 18.04
sudo apt install ros-noetic-cv-bridge    # Ubuntu 20.04
```

If you need a source build (see the
[OpenVINS instructions](https://docs.openvins.com/gs-installing.html#gs-install-opencv)):

```bash
git clone https://github.com/opencv/opencv/
git clone https://github.com/opencv/opencv_contrib/
mkdir opencv/build/
cd opencv/build/
cmake -DOPENCV_EXTRA_MODULES_PATH=../../opencv_contrib/modules ..
make -j8
sudo make install
```

## 4. Clone the AprilTag library

Use the `opencv4` branch if you built against OpenCV 4.

```bash
git clone https://github.com/rpng/apriltags-cpp.git
```

## 5. Build GTSAM

GTSAM is the only dependency you have to build yourself — Boost and Eigen ship
with most Linux distributions. Install the system libraries first:

```bash
sudo apt install libboost-all-dev libeigen3-dev libmetis-dev
```

Optionally add Intel TBB and MKL for multithreaded optimisation. This is a
speed-only step; the toolbox runs fine without it.

```bash
wget https://apt.repos.intel.com/intel-gpg-keys/GPG-PUB-KEY-INTEL-SW-PRODUCTS-2019.PUB
sudo apt-key add GPG-PUB-KEY-INTEL-SW-PRODUCTS-2019.PUB
rm GPG-PUB-KEY-INTEL-SW-PRODUCTS-2019.PUB
sudo sh -c 'echo deb https://apt.repos.intel.com/mkl all main > /etc/apt/sources.list.d/intel-mkl.list'
sudo sh -c 'echo deb https://apt.repos.intel.com/tbb all main > /etc/apt/sources.list.d/intel-tbb.list'
sudo apt-get update
sudo apt-get install intel-tbb-2020.0-088
sudo apt-get install intel-mkl-2020.0-088
```

Then [build GTSAM](https://gtsam.org/get_started/) and install it globally. Use
the *system* Eigen so that every package links against the same version:

```bash
git clone https://github.com/borglab/gtsam
mkdir gtsam/build/
cd gtsam/build/
cmake -DCMAKE_BUILD_TYPE=Release -DGTSAM_USE_SYSTEM_EIGEN=ON -DGTSAM_BUILD_WITH_MARCH_NATIVE=OFF ..
make -j6
sudo make -j6 install
echo 'export LD_LIBRARY_PATH=/usr/local/lib/:$LD_LIBRARY_PATH' >> ~/.bashrc
```

:::caution
Do not place the GTSAM sources inside the `src/` folder of the workspace —
catkin will try to build them as a package.
:::

## 6. Clone and build Open MVIS

```bash
git clone https://github.com/yangyulin/mvis.git
cd ..
catkin build
```
