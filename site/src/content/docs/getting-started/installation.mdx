Use this page to install MVIS and check that it works.

- **Pure Python:** installs with `pip` on Linux and macOS
- **No ROS:** there is no ROS dependency
- **Nothing to compile**

## One-step setup (recommended)

```bash
bash scripts/setup_env.sh
conda activate mvis
```

The script does three things:

1. Creates the `mvis` conda environment.
2. Installs every dependency.
3. Runs the test suite, so you know the install works before you point it at data.

## Manual install

```bash
pip install -e .
```

Detector backends (the code that finds the board in each image) are optional extras.
Install the ones your boards need:

```bash
pip install -e ".[apriltag]"    # AprilGrid (aprilgrid package)
pip install -e ".[aruco]"       # ArUco (opencv-contrib)
pip install -e ".[dev]"         # pytest
```

## Reading bags

We read ROS bags through [`rosbags`](https://pypi.org/project/rosbags/).
It is pure Python and needs no ROS installation:

```bash
pip install rosbags
```

So you can calibrate a ROS1 or ROS2 bag on a machine that has never had ROS on it.

:::caution[GTSAM needs NumPy 1.x]
Pin NumPy below 2:

```bash
pip install "numpy<2"
```

GTSAM 4.2 from pip is built against the NumPy 1.x ABI (the binary interface between compiled libraries).
With NumPy 2 installed, constructing `gtsam.Pose3(Rot3, np.array)` gives a **segfault**.
That is not an exception you can catch: the program crashes.
:::

## Check the install

```bash
mvis --help
```

You should see seven subcommands:

- `calibrate`
- `cam`
- `cam-imu`
- `apply-calib`
- `roundtrip`
- `run`
- `analyze`

The [CLI reference](/reference/cli/) documents each one.
