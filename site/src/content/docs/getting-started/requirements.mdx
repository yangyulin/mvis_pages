What Open MVIS needs in order to build and run, and what it is able to
calibrate. For the build steps themselves see
[Installation](/getting-started/installation/).

## Software dependencies

| Dependency | Version | Required | Notes |
|---|---|---|---|
| [ROS](http://wiki.ros.org/ROS/Installation) | Melodic / Noetic | yes | data is consumed as ROS bags |
| [GTSAM](https://github.com/borglab/gtsam) | 4.x | yes | the only dependency you must build from source |
| [OpenCV](https://github.com/opencv/opencv) | 3 or 4 | yes | `ros-*-cv-bridge` is sufficient |
| [OpenVINS](https://github.com/rpng/open_vins/tree/develop_v2.3) | v2.3 | yes | feature front-end |
| [apriltags-cpp](https://github.com/rpng/apriltags-cpp) | `opencv4` branch for OpenCV 4 | yes | AprilTag detection |
| Boost, Eigen, METIS | system packages | yes | `libboost-all-dev libeigen3-dev libmetis-dev` |
| [Intel TBB / MKL](https://software.intel.com/en-us/articles/installing-intel-free-libs-and-python-apt-repo) | 2020.0 | optional | multithreaded GTSAM — speed only |

## What can be calibrated

| Quantity | Symbol | Scope | Models / notes |
|---|---|---|---|
| Camera intrinsics | `fx, fy, cx, cy` | per camera | refined, or solved from scratch |
| Camera distortion | `k1…kn` | per camera | rad-tan, equidistant (fisheye) |
| IMU intrinsics | `Dw, Da, Tg` | per IMU | Kalibr or RPNG model |
| Gyroscope intrinsics | scale + misalignment | per gyro | Kalibr or RPNG model |
| Camera–IMU extrinsics | `R_CI, t_CI` | pairwise | rotation + translation |
| IMU–IMU extrinsics | `R_IiIj, t_IiIj` | pairwise | rotation + translation |
| Time offsets | `Δt` | pairwise | each sensor → base-IMU clock |
| Rolling-shutter readout | `tr` | per RS camera | first / middle / last row convention |

Any subset can be locked and the remainder solved — the switches are listed in
the [configuration reference](/reference/configuration/#what-to-calibrate).

## Calibration targets

Both target families are supported and are interchangeable:

- [Kalibr AprilGrid](https://github.com/ethz-asl/kalibr/wiki/calibration-targets) — recommended
- [ArUco boards](https://docs.opencv.org/4.x/d5/dae/tutorial_aruco_detection.html)

## Reference rig

The MVIS datasets were collected with a self-built VI-Rig. The rig is not
required to run the toolbox — it is the configuration that the shipped launch
files assume.

<Image src={viRig} alt="VI-Rig with 4 IMUs and 5 cameras" width="320" />

**Visual-Inertial (VI)-Rig** — 4 IMUs and 5 cameras:

| Sensor | Rate (Hz) | Topic | Resolution |
|---|---|---|---|
| MicroStrain GX3-25 | 500 | `/gx3_25/data` | — |
| MicroStrain GX3-35 | 100 | `/gx3_35/imu/data` | — |
| Xsens MTI-100 | 400 | `/imu/data` | — |
| RealSense T265 IMU | 200 | `/t265/imu` | — |
| FLIR BlackFly | 30 | `/blackfly/image_raw` | 720×540 |
| RealSense T265 Left | 30 | `/t265/fisheye1/image_raw` | 848×800 |
| RealSense T265 Right | 30 | `/t265/fisheye2/image_raw` | 848×800 |
| ELP Left (rolling shutter) | 25 | `/elp/split_sync_image_node/left/image_raw` | 640×480 |
| ELP Right (rolling shutter) | 25 | `/elp/split_sync_image_node/right/image_raw` | 640×480 |

ROS drivers for these sensors are collected in
[multi_sensor_drivers](https://github.com/yangyulin/multi_sensor_drivers). If no
driver exists for your sensor, the
[Kalibr bag creator](https://github.com/ethz-asl/kalibr/wiki/bag-format) will
build a bag from raw files.
