## Main Graph Formulation

Use this page to see the main cost functions for the calibration. The derivation
of each residual block has its own page, linked at the end.

The MVIS factor graph (a graph that links the unknowns to the measurements that
constrain them) optimises everything jointly. It finds a single
maximum-a-posteriori estimate: the most likely values given the measurements
and the priors. The graph solves for:

- **camera intrinsics** (each camera's own model parameters)
- **IMU intrinsics** (each IMU's own model parameters)
- **all extrinsics** (the poses between the sensors)
- **time offsets**
- **rolling-shutter readout times** (the time a rolling-shutter camera takes to
  read out one image)

Schematically:

$$
\arg\min_{\boldsymbol{x}} \;
\sum_{i,k} \rho\!\left(\| \mathbf{r}_{\text{cam}}^{i,k} \|_{\Sigma_c}^2\right) +
\sum_{j,k} \rho\!\left(\| \mathbf{r}_{\text{imu}}^{j,k} \|_{\Sigma_i}^2\right) +
\sum_{j,k} \rho\!\left(\| \mathbf{r}_{\text{imu-imu}}^{j,k} \|_{\Sigma_{ij}}^2\right) +
\Pi(\boldsymbol{x}, \boldsymbol{\mu}_0)
$$

where:

- $\boldsymbol{x}$ is the full calibration state vector;
- $\rho(\cdot)$ is a robust loss (Huber), which down-weights large residuals;
- $\Pi$ encodes Gaussian priors on each calibration parameter.
