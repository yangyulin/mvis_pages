## Observability Analysis

Coming soon. We will add an observability analysis of the MVIS calibration
state (the set of parameters MVIS estimates). A parameter is observable when
the measurements are enough to estimate it.

The analysis will cover:

- **Unobservable directions:** yaw and global position, which the data cannot fix.
- **Conditions for observability:** when each of these parameters becomes observable:
  - intrinsic
  - extrinsic
  - time-offset
  - rolling-shutter
