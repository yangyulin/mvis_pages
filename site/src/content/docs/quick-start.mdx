## Test with the simulator

After compilation, you can quickly test MVIS with simulation.

<Image src={simEnv} alt="Simulation environment" width="400" />

**Simulation environment**

- 1 base IMU
- 2 auxiliary IMUs
- 1 auxiliary gyro
- 2 rolling-shutter cameras

Run the simulation:

```bash
source devel/setup.bash
roslaunch mvis yulin_sim_multi_imu.launch
```

You need to specify the `OUTPUT_FOLDER` for the results:

```xml
<arg name="dosave_state"   default="true" />
<arg name="path_state_est" default="OUTPUT_FOLDER/state_est.txt" />
<arg name="path_state_std" default="OUTPUT_FOLDER/state_std.txt" />
<arg name="path_state_gt"  default="OUTPUT_FOLDER/state_gt.txt" />
<arg name="dosave_calib"   default="true" />
<arg name="path_calib_est" default="OUTPUT_FOLDER/$(arg dataset)_calib_results.txt" />
```

During the run, RViz is recommended to check the estimated trajectory and map. Use the display setup at:

```
src/mvis/launch/display.rviz
```

Check the simulation results:

```bash
rosrun mvis error_simulation \
  OUTPUT_FOLDER/state_est.txt \
  OUTPUT_FOLDER/state_std.txt \
  OUTPUT_FOLDER/state_gt.txt
```

You can also use the shell scripts:

```bash
./src/mvis/paper_scripts/show_sim_single.sh
```

## Test with real-world datasets

### 1 base IMU + 3 auxiliary IMUs + 3 global-shutter cameras

Download the [example dataset](https://drive.google.com/file/d/1ZUkDktq_DBdnaLh7aiQVUBIG_TcgvGgi/view?usp=sharing) collected using the VI-Rig.

```bash
source devel/setup.bash
roslaunch mvis yulin_virig_for_mvis_3cams.launch
```

Specify the dataset name and path:

```xml
<arg name="dataset"  default="virig_4imus_3cams_april_01" />
<arg name="bag_path" default="DATASET_PATH/$(arg dataset).bag" />
```

### 1 base IMU + 3 auxiliary IMUs + 2 global-shutter + 2 rolling-shutter cameras

Download the [example dataset](https://drive.google.com/file/d/11gMv9ch3_QkINdy6aMoGMROmXcOkp0Ug/view?usp=sharing) collected using the VI-Rig.

```bash
source devel/setup.bash
roslaunch mvis yulin_virig_for_mvis_init_large_errors.launch
```

Specify the dataset:

```xml
<arg name="dataset"  default="virig_4imus_3cams_april_01" />
<arg name="bag_path" default="DATASET_PATH/$(arg dataset).bag" />
```

Specify how an auxiliary IMU is used (full IMU vs gyro-only):

```xml
<arg name="imus_s_mode" default="[0, 0, 0]" /> <!-- 0: full imu, 1: gyro only -->
```

**Full IMU** uses both accelerometer and gyroscope; **Gyro only** uses only the gyroscope.
