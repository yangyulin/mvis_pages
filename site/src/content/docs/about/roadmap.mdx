Use this page to see what we plan after MVIS 0.1.0. These are intentions, not
commitments with dates. What shipped is on the [Changelog](/about/changelog/).

## Toolbox

| Item | Status |
|---|---|
| `pip install pymvis` from PyPI | with the v0.1.0 release; until then, install from source ([Installation](/getting-started/installation/)) |
| Public code repository | done: [github.com/openmvis/openmvis](https://github.com/openmvis/openmvis), GPL-3.0-only with a commercial licence ([License](/about/license/)) |
| `omni_radtan` | experimental in 0.1.0 |
| Stable config schema | not before 1.0: 0.x releases may change it |
| Windows, Python 3.13 | blocked upstream: GTSAM has no Windows wheels, and the NumPy 1.x that GTSAM 4.2 needs has no 3.13 wheel |

## Documentation

The [CLI](/reference/cli/), [Configuration](/reference/configuration/) and
[Python API](/reference/python-api/) pages were checked against MVIS 0.1.0.
When they differ from the code, `mvis <command> --help` and `mvis check` are
authoritative.

## Not planned

- **Replacing Kalibr for single-IMU rigs.** Kalibr is mature and widely used.
  MVIS adds what Kalibr does not cover, such as rolling-shutter readout on
  several cameras, camera–camera time offsets, the gyro–accel offset `t_ga` and
  the board shape. See
  [Comparison](/getting-started/comparison/).
- **A single combined score on the leaderboard.** How to weigh one parameter
  against another is the reader's call, not the benchmark's. See
  [Methodology](/benchmark/methodology/).
