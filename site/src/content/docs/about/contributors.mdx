## Citing Open MVIS

If you use the toolbox or the benchmark, please cite:

```bibtex
@misc{openmvis,
  title  = {{Open MVIS}: A Benchmark for Multi-Visual-Inertial Sensor Calibration},
  author = {{Open MVIS Contributors}},
  year   = {2026},
  url    = {https://openmvis.com}
}
```

## Citing the leaderboard

Leaderboard snapshots are versioned so a comparison stays citable after later
submissions land. Cite the snapshot, not the live page:

> Open MVIS leaderboard vX.Y, accessed &lt;date&gt;.
> https://openmvis.com/benchmark/leaderboard/

See [Methodology](/benchmark/methodology/) for what the numbers mean.

## Citing the datasets

Each released dataset has its own citation and DOI, given on its page — see
[Datasets](/reference/datasets/). Cite the dataset in addition to the toolbox
when your results depend on it.

## Contributing

Contributors of datasets and verified results are credited here. See
[Governance](/contribute/governance/) for how credit and co-authorship are
handled, and [Contribute](/contribute/submit-results/) to get started.
