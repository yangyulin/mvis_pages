Use this page to see who builds MVIS and how to cite it.

- **OpenMVIS:** the project.
- **MVIS:** the calibration toolbox, installed as the Python package `pymvis`.
- **Calibench:** the datasets and results on
  [Hugging Face](https://huggingface.co/calibench-vi).

## Maintainer

- **Yulin Yang:** author and maintainer of MVIS
  ([personal website](https://yangyulin.net)).
- **Contact:** contact@openmvis.com. Licensing questions go to
  licensing@openmvis.com.

## Contributors

- **Yuantai-Z:** camera-only pipeline fixes (outlier rejection, pose alignment,
  frame selection) and the ROS1 recalibration tool (`tools/ros1_recalib`).

The list follows
[`AUTHORS`](https://github.com/openmvis/openmvis/blob/main/AUTHORS) in the MVIS
repository. We add people who contribute code, datasets or results.

2024), written at the [Robot Perception and Navigation Group
(RPNG)](https://sites.udel.edu/robot/), University of Delaware.

## Citing MVIS

Cite the software and the MVIS paper, as
[`CITATION.cff`](https://github.com/openmvis/openmvis/blob/main/CITATION.cff)
asks. The paper is the preferred citation.

```bibtex
@article{yang2024mvis,
  title   = {Multi-visual-inertial system: Analysis, calibration, and estimation},
  author  = {Yang, Yulin and Geneva, Patrick and Huang, Guoquan},
  journal = {The International Journal of Robotics Research},
  year    = {2024},
  volume  = {43},
  number  = {13},
  pages   = {1995--2026},
  doi     = {10.1177/02783649241245726}
}
```

The software, with the version you ran:

```bibtex
@software{mvis,
  title   = {{MVIS}: camera and camera-IMU calibration toolbox},
  author  = {Yang, Yulin},
  version = {0.1.0},
  year    = {2026},
  url     = {https://github.com/openmvis/openmvis},
  license = {GPL-3.0-only}
}
```

## Citing the benchmark

If you compare against the benchmark results, cite the benchmark:

```bibtex
@misc{openmvis,
  title  = {{Open MVIS}: A Benchmark for Multi-Visual-Inertial Sensor Calibration},
  author = {{Open MVIS Contributors}},
  year   = {2026},
  url    = {https://openmvis.com}
}
```

Results come in dated batches. Name the batch you used, so the comparison stays
citable after later batches land:

> OpenMVIS leaderboard, batch 2026-11-10a, accessed &lt;date&gt;.
> https://openmvis.com/benchmark/results/

The batch shown on the [Leaderboard](/benchmark/results/) is the current one.
[Methodology](/benchmark/methodology/) explains what the numbers mean.

## Citing the datasets

When your results depend on a dataset, cite the dataset as well as MVIS.

- **VI-Rig recordings (our own):** cite Calibench for every VI-Rig set. For the
  4-IMU sets (`virig-4imus-3cams`, `virig-4imus-3cams-aruco` and
  `virig-4imus-4cams`), also cite the MVIS paper above. `virig-5imus-4cams` has
  no paper yet; cite Calibench only. The Calibench entry is on
  [Datasets](/datasets/).
- **Third-party datasets:** cite the original authors. The
  [dataset card](https://huggingface.co/datasets/calibench-vi/datasets) lists
  the citation each one requires.
