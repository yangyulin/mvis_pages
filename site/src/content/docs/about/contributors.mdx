## Citing Open MVIS

If you use the toolbox or the benchmark, please cite:

```bibtex
@misc{openmvis,
  title  = {{Open MVIS}: A Benchmark for Multi-Visual-Inertial Sensor Calibration},
  author = {{Open MVIS Contributors}},
  year   = {2026},
  url    = {https://openmvis.com}
}
```

## Citing the leaderboard

Cite the leaderboard snapshot, not the live page. Snapshots are versioned, so a
comparison stays citable after later submissions land. Use this form:

> Open MVIS leaderboard, batch 2026-11-04a, accessed &lt;date&gt;.
> https://openmvis.com/benchmark/results/

See [Methodology](/benchmark/methodology/) for what the numbers mean.

## Citing the datasets

When your results depend on a dataset, cite the dataset as well as the toolbox.

- **Citation and DOI:** each released dataset has its own, given on its page.
- **Where to find them:** see [Datasets](/datasets/).
