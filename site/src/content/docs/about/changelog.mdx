## MVIS 0.1.0

The first public release. There is no earlier public version, so the list
describes the toolbox as it ships. On 2026-11-12 the release was not yet tagged.

- **Package:** `pymvis` (import and command `mvis`), Linux and macOS, Python
  3.11 and 3.12.
- **Licence:** GPL-3.0-only, with a commercial licence for closed-source
  products. See [License](/about/license/).

### Calibration

- **Camera-only** (`mvis cam`): one or more cameras; intrinsics, distortion,
  extrinsics, camera–camera time offset and rolling-shutter readout (the time
  the sensor takes to read the image row by row).
- **Camera–IMU** (`mvis cam-imu`): camera–IMU extrinsics, time offset `td`,
  readout, camera intrinsics, IMU intrinsics, biases, the base IMU's
  gyro–accel offset `t_ga`, and the extrinsics and time offsets of further IMUs.
- **Camera models:** eight, usable in both modes and mixed within one rig:
  `radtan`, `equidistant`, `kb4`, `fov`, `double_sphere`, `eucm`, `ucm` and
  `omni_radtan` (experimental). `fisheye` means `kb4`.
- **IMU conventions:** `kalibr`, `rpng` and `calyx`, with scale and
  misalignment (`Dw`, `Da`) and optional g-sensitivity (`Tg`).
- **`estimate:` block:** chooses what is solved and what is held, including the
  board shape (`board_points`).
- **One command for both modes:** `mvis run` runs either mode from one config
  (`mode: cam` or `mode: cam-imu`).
- **Batch:** `input.bags` calibrates a whole set of recordings from one config.

### Input and output

- **Inputs:** image folders, timestamped images, ROS1 bags (`Image`, and PNG or
  JPEG `CompressedImage`), ROS2 bags and EuRoC / ASL folders.
- **ROS2 without ROS:** ROS2 bags (a bag folder, or one `.db3` or `.mcap` file)
  are read with the pure-Python `rosbags`, with no ROS install.
- **Boards:** AprilGrid, chessboard and ArUco.
- **Kalibr interop:** read and write Kalibr camchains.
- **Output:** YAML calibration files, JSON results and self-contained HTML
  reports for both modes.
- **Datasets:** `mvis datasets` lists, downloads and verifies the Calibench
  datasets on Hugging Face.

### Tools

- **`mvis apply-calib`:** writes a corrected copy of a ROS1 bag: IMU intrinsics
  and bias removed, streams re-stamped by `td`, accelerometer shifted by `t_ga`,
  images optionally undistorted.
- **`mvis roundtrip`:** calibrates, applies the result, calibrates again, and
  gives a PASS/FAIL report. ROS1 bags only.
- **`mvis check`, `mvis inspect`, `mvis verdict`:** check the environment and
  config, summarise a dataset, and grade a finished result.
- **Simulator** (`mvis.simulation`): digital twins of real recordings.

### Why calibrate (2026-11-10 and 2026-11-12)

A section on what each calibrated quantity changes: [IMU](/why/imu/),
[t_ga](/why/tga/), [board shape](/why/board-shape/),
[fisheye model (kb4)](/why/kb4/), [rolling shutter](/why/rolling-shutter/),

### Leaderboard shows results, not scores (2026-11-03)

Each dataset shows the results of MVIS, Kalibr and Basalt side by side, with
the differences between them. There are no scores or ranks. See
[Methodology](/benchmark/methodology/).

### Move to Astro + Starlight (August 2026)

The site moved from jemdoc to Astro + Starlight, with search, dark mode and
KaTeX maths. The old `openmvis.com/*.html` pages redirect.

## Datasets

The datasets are on
[Hugging Face](https://huggingface.co/datasets/calibench-vi/datasets). Each set
and its licence is listed on [Datasets](/datasets/).

- **VI-Rig recordings (ours):** multi-camera, multi-IMU recordings, CC BY-NC 4.0
  and gated.
- **Partner recordings:** Looper and GiLabs, on the same terms.
- **Converted third-party sets:** Monado MIC, MGC and MOC, and the TUM-VIE frame
  cameras, CC BY 4.0.
