## Documentation site

### Guide-site restructure

The documentation was reorganised from five sections into eight, following a
tutorial / guide / concept / reference / example separation
([Governance](/contribute/governance/) states the rule). Practical consequences:

- **Getting started** now separates Requirements, Installation, and Quickstart —
  previously one Compilation page and a mixed Quick Start.
- **Guides** are task-oriented and no longer explain theory. Camera calibration,
  rolling shutter, multi-sensor rigs, and simulation each have their own page.
- **Concepts** collects the maths, with a shared
  [notation and glossary](/concepts/notation/).
- **Reference** holds the exhaustive material — configuration, CLI, result
  formats, evaluation, datasets.
- **Examples** became a per-dataset gallery with validation against external
  references.
- Old URLs redirect. The legacy `openmvis.com/*.html` pages redirect too.

### Initial Starlight site

Migrated from jemdoc to Astro + Starlight: KaTeX maths, search, dark mode,
edit-this-page links, and the first leaderboard prototype.
