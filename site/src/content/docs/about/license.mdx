## Toolbox

CamCalib declares the **MIT License** in its `pyproject.toml`.

MIT is permissive: use, modify, and redistribute — including in closed-source
products — provided the copyright notice and licence text travel with it.

:::caution[No LICENSE file yet]
The declaration lives in package metadata; the repository does not yet carry a
`LICENSE` file with the full text. Until it does, treat this page as
*indicative* rather than authoritative. Adding the file is on the
[roadmap](/about/roadmap/).
:::

## This site

[`yangyulin/mvis_pages`](https://github.com/yangyulin/mvis_pages) — source,
content, and generated pages — is released under the **MIT License**. Prose and
figures here can be reused with attribution.

## Datasets

Released datasets carry their own licences, stated on each dataset's page — see
[Datasets](/reference/datasets/). Contributed datasets need a licence permitting
redistribution and derivative results; CC BY 4.0 is the usual choice. See
[Submit a dataset](/contribute/submit-dataset/).
